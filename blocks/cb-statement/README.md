# cb-statement

Cobrand **cb-statement** block. Purpose: one display-size serif statement on an immersive black section, with an optional attribution (DESIGN.md § Components).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Row 1: the statement, preferably as a heading (Heading 2). Row 2 (optional): attribution text. Put the block in its own section with section metadata `style: center, black`; if the section has no ground, the block adds the black ground.

At most one per page. Use only verbatim, attributed quotations or programme statements.

## Supported variations

No variations.
